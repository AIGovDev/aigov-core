# Public launch checklist

## Technical readiness

- [ ] Exact PR head CI is green and reviewed; do not auto-merge.
- [ ] The canonical viewer and packaged Space pass synchronization and regression checks.
- [ ] Public Space URL is verified; valid, tampered, malformed, oversized and XSS-shaped inputs are tested.
- [ ] Browser checks cover desktop and narrow mobile view.
- [ ] Five-minute quickstart is reproduced from a clean checkout.
- [ ] Architecture and export examples resolve.
- [ ] Benchmark copy reports the actual 20-scenario study, false accepts, sample size and absent live-agent run.
- [ ] Independent audit status is described as preparation, not a completed audit.

## Communications

- [ ] Choose dates and confirm current platform/community rules.
- [ ] Use platform-specific drafts; do not copy identical promotional text into multiple communities.
- [ ] Do not request artificial stars, votes or reciprocal engagement.
- [ ] Do not imply partnership or endorsement by Hugging Face, OpenAI, Anthropic or another organization.
- [ ] Add a verified demo link only after publication.

## Measurement

- [ ] Save the pre-launch metrics snapshot and report timestamp.
- [ ] Record each channel and publication time in the private tracker.
- [ ] Collect weekly counters and package statistics; retain unavailable values as unavailable.
- [ ] Separate promotion activity from organic contributors, issues and pull requests.
- [ ] Avoid interpreting downloads or stars as unique users or deployments.
