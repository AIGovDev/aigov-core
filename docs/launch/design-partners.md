# Design-partner invitation draft

**Subject:** Feedback on a policy-gated evidence runtime for AI systems

Hello,

I am building AIGov Core, an AGPL-3.0 Rust audit runtime with Python tooling. It records supplied evidence in tenant-scoped ledgers, applies a configured policy, and derives an explicit VALID / INVALID / BLOCKED state that can be exported for review.

I am looking for a small number of engineering or governance teams to critique the integration model and trust boundaries using synthetic data or a non-production deployment. AIGov Core does not prove that submitted evidence is true or complete, that an external action occurred, or that a system complies with law.

Would a short technical review be useful? I can share the local quickstart and the current security review scope. This is a request for feedback, not an offer of legal certification or a claim of a production-ready managed service.
