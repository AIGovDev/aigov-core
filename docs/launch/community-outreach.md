# Community outreach

## Hugging Face

Share the static evidence viewer only after it is deployed and the public URL, privacy behavior, malformed inputs and mobile layout are verified. Describe it as a local-in-browser consistency viewer. Do not claim Hugging Face endorsement.

## Reddit and technical forums

Choose one relevant community at a time. Read its current self-promotion rules, disclose maintainer status, ask for technical critique, and do not request stars, votes or reciprocal engagement.

## Technical newsletters

Send the prepared pitch only to an editor whose published scope includes open-source engineering, AI infrastructure, security or governance. A pitch is not an accepted feature.

## Catalogs

Use the separately maintained catalog research. Recheck current activity, existing listings, category, contribution license and generated-file requirements before opening each external PR. One focused catalog PR per receiving repository; record exact URL and state.

No external outreach or catalog submission is implied by this playbook.
