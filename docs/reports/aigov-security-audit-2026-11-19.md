## Findings

### FINDING-01 — FIXED — payload_intact check always returned PASS (Medium)

**File:** `python/aigov_py/agent_action_verification.py:310`
**Severity:** Medium
**Status:** FIXED in this PR

**Description:**
```python
# Before (broken — compares computed property to itself):
recomputed = pkg.proposal.payload_digest
checks["payload_intact"] = "PASS" if recomputed == pkg.proposal.payload_digest else "FAIL"

# After (correct — re-derives from canonical_payload, compares to approver-recorded digest):
recomputed = "sha256:" + hashlib.sha256(pkg.proposal.canonical_payload).hexdigest()
checks["payload_intact"] = "PASS" if recomputed == pkg.approval.approved_payload_digest else "FAIL"
```

**Impact:** A `payload_intact` FAIL could not be generated by any payload substitution
attack — the check always returned PASS. With the fix, an EvidencePackage
carrying a legitimately approved approval but a different proposal body now
correctly fails `payload_intact`. Regression test AAV-15 added.

**Exploitability:** Low for in-memory Python objects (frozen dataclasses cannot be
mutated); higher when packages are deserialized from untrusted network/storage
sources (e.g. JSON over HTTP). The `chain_integrity` check would still catch
most tampering attempts, but `payload_intact` provides an independent guard.

### FINDING-02 — ADVISORY — HashMap API key lookup (not constant-time) (Low)

**File:** `rust/src/audit_api_key.rs:116,125`
**Severity:** Low
**Status:** Advisory — acceptable for internal service mesh

Rust `HashMap::get` / `contains_key` is not constant-time. An adversary with
network access and timing measurement capability could probe key membership.
AIGov Core is intended as an internal audit service (not publicly exposed);
rate limiting mitigates brute-force attempts. Recommend upgrading to a
constant-time map (e.g. `subtle::ConstantTimeEq`) before public SaaS exposure.
