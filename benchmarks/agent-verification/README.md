# AIGov Agent Verification Benchmark

Publicly reproducible benchmark demonstrating the difference between an agent
*reporting* success and an *independently verified* successful action.

## Quick start

```bash
# Generate dataset (140 deterministic synthetic cases; seed=42)
python benchmarks/agent-verification/dataset_generator.py \
    --out-dir benchmarks/agent-verification/data --seed 42 --cases 140

# Run benchmark on dev split
python benchmarks/agent-verification/run_benchmark.py \
    --data-dir benchmarks/agent-verification/data --split dev

# Run on held-out evaluation split
python benchmarks/agent-verification/run_benchmark.py \
    --data-dir benchmarks/agent-verification/data --split held_out
```

No paid API credentials required. Fully local execution. Deterministic output.

## Evaluation conditions

| ID | Name | Evidence received |
|----|------|-------------------|
| A | Agent self-report | Agent's own claim ("success"/"failure") |
| B | Tool-response | Execution API return code |
| C | Independent state | Direct read-back of target system state |
| D | AIGov evidence | Approval binding + chain integrity + independent state + execution match |

## Positive class

`AUTHORIZED_CORRECT` — the action was authorized by a valid, non-replayed
human approval bound to the exact canonical payload, executed correctly, and
independently confirmed by read-back.

## Scenario taxonomy

14 scenario types covering:

**Authorization failures:** `MISSING_APPROVAL`, `EXPIRED_APPROVAL`,
`REPLAY_ATTACK`, `POST_APPROVAL_MUTATION`, `WRONG_TENANT`

**Execution failures:** `INCORRECT_FINAL_STATE`, `PARTIAL_EXECUTION`,
`POST_EXECUTION_OVERWRITE`

**Evidence failures:** `EVIDENCE_TAMPERED`, `BROKEN_EVIDENCE_CHAIN`,
`STALE_READBACK`

**Tool failures:** `TOOL_ERROR`, `TOOL_RESPONSE_MISMATCH`

## Confusion matrix semantics

- **TP** — truly authorized+correct, detector says PASS
- **FP** — not truly authorized+correct, detector says PASS ← false acceptance
- **FN** — truly authorized+correct, detector says FAIL ← false rejection
- **TN** — not truly authorized+correct, detector says FAIL

## Metrics reported

TPR (True Positive Rate / Recall), FPR (False Positive Rate),
Precision, F1, FAR (False Acceptance Rate), FRR (False Rejection Rate),
average latency per decision (µs), 95 % Wilson score confidence intervals
where sample size justifies it.

## Limitations and threat model

- Dataset is entirely synthetic. Real-world base rates differ.
- Condition A (self-report) is intentionally baseline; it reflects agents
  that do not perform any external check.
- Condition D accuracy depends on the integrity of the AIGov evidence system
  itself; this benchmark does not evaluate that layer's attack surface.
- Deterministic RNG means the held-out split is reproducible but not
  independently collected; treat it as a proxy for generalization, not a
  guarantee.
- No network, no GPU, no paid API. Benchmarks that require inference latency
  are out of scope here.
